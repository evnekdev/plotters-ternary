# N-dimensional extension roadmap

The 0.1.0 crate deliberately specializes in the symmetric regular triangular
ternary lattice. A future independent numerical crate may generalize directed
alpha intervals, pairwise extrapolation, local simplex fields, and isosurface
projection to N-component composition spaces.

Kuhn simplices, arbitrary triangulation, and N-component APIs are not part of
this crate. See the preserved detailed roadmap in
[`source/06_nd_extension/kuhn_simplex_roadmap.md`](source/06_nd_extension/kuhn_simplex_roadmap.md).
